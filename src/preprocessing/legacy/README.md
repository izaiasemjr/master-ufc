# Historical source snapshot

The three Python scripts in this directory were copied unchanged from
`MESTRADO-CODIGOS-IZAIAS/preproceessing/` on 2026-10-06. They are preserved to
trace the dissertation implementation, but are intentionally not the entry
point for new experiments:

- `preprocessing.py` contains fixed paths and the original `N`/`O` selection;
- `view_outliers.py` is an interactive inspection script;
- `view_grids.py` compares voxel sizes interactively.

Generated `.pcd` visualizations, PCL viewer camera files, and the historic
timing file were not copied because they are outputs rather than source code.
